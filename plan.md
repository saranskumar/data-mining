## Steps
0. **Scaffold** — folders, `requirements.txt`, `.gitignore`, `config.yaml`, `README.md`, `utils/` stubs. CUDA torch install note for RTX 2050. *Exit:* imports work, `torch.cuda.is_available()`.
1. **`01_preprocess.py`** — load, validate, dedupe (hash), split 90/10 + official test, `--subset N`, EDA figs, `data_quality.txt`.
2. **`utils/feature_utils.py` + `02_feature_extraction.py`** — 4 groups (noise, FFT/DCT, colour, GLCM), multiprocessing, cache, `feature_names.json`, per-feature separation chart. Unit tests per group. *Run on subset first; user runs full.*
3. **`03_pca_reduce.py`** — scaler+PCA fit on train only (assert), scree/loadings/2-D scatter.
4. **`04_classify.py`** — dummy/LogReg, DT-Gini, DT-Entropy, MLP, grids on val, test once, CV, ROC-AUC, ablation, error grid, pre-PCA tree importances, McNemar.
5. **`05_cluster.py`** — K sweep 2–12, elbow/silhouette, purity/ARI/NMI vs real/fake, scatter, narrative.
6. **`utils/wm_model.py` + `06_watermark_train.py`** — Encoder/Decoder/NoiseLayer, overfit-tiny-batch test, curriculum, AMP, fallback ladder gates (val bit-acc ≥0.9, PSNR ≥30).
7. **`utils/attacks.py` + `07_watermark_eval.py`** — bit-acc, exact match, PSNR/SSIM, real-attack table, binomial threshold from unmarked images, residual grid, interaction study.
8. **`08_hybrid_eval.py`** — fusion rule on 4 groups × clean/attacked; SynthID qualitative table.
9. **`app/demo.py`** — Detect / Watermark / Hybrid tabs, sample gallery, error handling.
10. **Report support** — all tables generated by scripts into `outputs/tables/`; fill deck "no scores" slides with measured numbers; add watermark paragraph to abstract.

11. **Modern-generator OOD set (required)** — `code/data_ood/build_modern.py` streams a capped sample from newer HF datasets (GPT Image2 / Nano Banana2, Nano Banana Pro + MJ/DALL-E/SD, Flux/SDXL), resizes to 32×32 the CIFAKE way, saves `X_img_ood.npy`, `y_ood.npy`, `meta_ood.csv` (source, generator, label). `09_ood_eval.py` then scores saved models per generator and reports the drop vs CIFAKE; optional retrain with a generator-held-out split. *Never mixed into CIFAKE training for headline numbers.* Caveats for report: reals differ per source (source-shortcut risk), research-only licences, 32×32 erases most artefacts.

Sources: `zr-zhang/MLLM-Generated-Image-Detection-Dataset`, `julienlucas/midjourney-dalle-sd-nanobananapro-dataset`, `Shanmuk4622/ai-image-detection-dataset` (Flux/SDXL), optionally DailyBench (arXiv 2607.24016, unchecked).
