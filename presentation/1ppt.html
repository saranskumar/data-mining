01 / Problem

Can we trust an image anymore?

Generators

  • Stable Diffusion
  • Midjourney
  • DALL-E

Risks

  • Misinformation
  • Fraud
  • Impersonation
  • Misrepresentation

Why hard

  • Both look visually plausible
  • Eye cannot see sensor vs synthesis traces
  • Need statistical signals
  • Visual match vs hidden traces
02 / Solution

Two complementary layers

Layer 1 Forensic detection

  • Analyze the image itself
  • No watermark required
  • Extract forensic features
  • PCA then Decision Tree / MLP
  • Output: Real or Fake

Layer 2 Learned watermarking

  • Embed an invisible message
  • Encoder hides bits in the image
  • Attacks: JPEG, crop, resize
  • Decoder recovers the message
  • Output: provenance signal
  • Detect what is present
  • Verify what is marked
03 / Dataset

CIFAKE

Facts

  • Total: 120,000 images
  • Train: 100,000 (50k real / 50k fake)
  • Test: 20,000 (10k real / 10k fake)
  • Resolution: 32 × 32 RGB
  • Real source: CIFAR-10 photographs
  • Fake source: Stable Diffusion v1.4
  • Classes are balanced
  • Limitation: 32×32 is far below real-world size
  • Split counts
  • Not experimental results
  • Resolution limitation

05 / Data Mining Pipeline

From features to classification

  • PCA keeps important variation
  • Drops extra dimensions
  • Feature vector can be high-dimensional
  • PCA reduces dimensions before classifiers
  • Decision Tree and MLP both see the same reduced vector
  • Final label: Real / Fake
06 / Classification & Clustering

Why these algorithms?

Decision Tree

  • Interpretable baseline
  • Fast
  • Shows feature importance
  • Splits: Information Gain / Gini
  • Rule splits

MLP

  • Comparison model
  • Learns non-linear links
  • Less interpretable
  • Hidden layers

K-Means

  • Exploration only
  • Not the main classifier
  • Do clusters track real/fake? (weakly: ARI 0.08)
  • Feature-space groups
07 / Learned Watermarking

Encoder → Noise → Decoder

  • Inspired by WAM
  • Not claimed as identical implementation

Input

  • Cover image
  • Message bits, e.g. 10110101

Goal

  • Hidden message
  • Visually similar image
  • Survive transforms

Not the same as detection

  • Detection: analyze existing traces
  • Watermark: embed a signal
08 / Evaluation & Limitations

How do we know it works?

Classification (CIFAKE test, n = 19,622)

  • MLP (128, 64): 93.5 % acc · F1 0.933 · AUC 0.983
  • Logistic regression: 89.8 %
  • Decision tree, Gini: 85.1 % · entropy (IG): 84.7 %
  • McNemar MLP vs DT: p < 0.001
  • Top feature: FFT radial band 7 (high frequency)

Clustering + watermark

  • K-Means best k = 2 (silhouette 0.11)
  • Purity 0.65 · ARI 0.08 → clusters barely track real/fake
  • Watermark: 16 bits, 100 % read back on full-size photos (43 dB)
  • All numbers produced by the pipeline scripts

Limitations

  • CIFAKE is only 32×32
  • Fails on modern generators (~50 %)
  • Transforms can damage watermarks
  • Detection ≠ exact source
  • Academic prototype
08b / Results on modern generators

Trained on SD 1.4 fakes, tested on current generators

Out-of-distribution test (4,999 images, 32×32)

  • Fakes: GPT Image 2, Nano Banana 2, FLUX.2, Qwen Image 2.1, MJ / DALL-E / SD / Nano Banana Pro mix
  • Same features, scaler, PCA and models — nothing retrained
  • Balanced accuracy: ≈ 0.50 for every model (chance)
  • MLP calls ~77 % of everything "real" → detects only ~22 % of modern fakes

What it means

  • Classical features learned SD 1.4 / CIFAR-specific traces, not "AI-ness"
  • Detection must be retrained per generator generation
  • Motivates the provenance layer: a watermark does not age

08c / Watermark results

Invisible at full size, readable after JPEG

How it is applied to a real photo

  • Encoder/decoder trained on 90 k CIFAKE images (32×32), 16-bit message
  • Residual computed at 32×32 → upsampled → added to the original-size photo
  • Bounded change (tanh, α = 0.03), zero-mean → no colour tint
  • Perceptual masking: less change in flat areas (sky, paper)
  • Embed-and-verify: strength raised only if the message would not read back

150 real photos, strength 0.75

  • PSNR 43.2 dB · SSIM 0.998 (not visible)
  • False positives on unmarked photos: 0 / 150 (threshold 15/16 bits, p ≈ 2.6·10⁻⁴)
  • Watermarking changed only 3.4 % of forensic verdicts
  • Limit: cropping breaks it (spatial pattern shifts)
  • Source: outputs/tables/watermark_fullres.csv (mode = verified)
