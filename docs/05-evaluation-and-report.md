# Evaluation Protocol, Experiments & Report Plan

## 1. Evaluation rules (non-negotiable)
1. **Test set is touched once**, after all tuning. Tuning uses the validation split / CV on train.
2. Scaler, PCA, thresholds: **fit on train only**.
3. Positive class = FAKE (1). Report precision/recall/F1 for it, plus macro averages.
4. Single global seed; for headline numbers, repeat with 3 seeds (DT/MLP/K-Means) and report mean ± std.
5. Every table/figure is generated by a script into `outputs/`; the report copies from there.
6. Report negative results as results.

## 3. Metric definitions
- Accuracy, Precision = TP/(TP+FP), Recall = TP/(TP+FN), F1; ROC-AUC from `predict_proba`.
- Purity = Σ_k max_j |C_k ∩ L_j| / N; ARI, NMI from `sklearn.metrics`.
- PSNR (dB) and SSIM (`skimage.metrics`) between cover and marked.
- Bit-accuracy = fraction of correctly recovered bits (chance = 0.5); exact-match = all L bits correct.
- Watermark detection threshold: smallest k with `P(Binomial(L,0.5) ≥ k) ≤ α` (α≈1e-3), then verify empirical FPR on unmarked test images.
