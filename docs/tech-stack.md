# Tech Stack — HybridMarker

## Runtime
- Python 3.10+

## Core Libraries
| Concern | Library |
|---------|---------|
| Image I/O | Pillow, OpenCV |
| Numerical | NumPy, SciPy |
| Feature extraction | scikit-image |
| ML / DM | scikit-learn |
| Neural network | scikit-learn MLPClassifier |
| Dimensionality reduction | scikit-learn PCA |
| Watermark CNN | PyTorch (encoder / decoder) |
| Plotting | matplotlib, seaborn |
| Dataset | CIFAKE (Kaggle) |

## Environment
- venv
- requirements.txt at project root
